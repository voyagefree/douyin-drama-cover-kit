# 短视频解说发布文案规范

适用于抖音/视频号/B站等平台的影视剧解说账号。

## 标题风格

### 封面标题（大字，两行，每行 ≤5 字）
- 四字短语最佳，对仗或反差
- 口语化，不要书面语
- 留钩子：疑问、反差、悬念
- 示例：
  - ✅ 人去楼空 / 物是人非
  - ✅ 一念之差 / 满盘皆输
  - ✅ 三个字 / 我不说
  - ❌ 第十八集甄嬛在碎玉轩的孤独岁月（太长太书面）

### 发布标题（feed 流，20 字左右）
前 15 字必须有钩子，格式：
- **悬念式**：她入宫前那晚，没人知道她怀了龙种
- **反差式**：这个丫鬟被抽得流血，咬死三个字没招
- **疑问式**：为什么这版剧，十几年了还在被吹？
- **数字式**：10 分钟看完这部剧的开局，全程高能

每集给 3 个备选：主推 1 个 + 备选 2 个。

## 话题标签

每条必带：
```
#剧名 #主演名 #电视剧解说 #影视解说 #好剧推荐
```
单集追加：
- 人物向：#主角名 #关键角色名（本集核心人物）
- 版本向：#演员名（对应版本主演）
- 形式向：#一口气看完（仅合集/先导）
- 情绪向：#意难平 #意难平系列（悲剧章节）

控制在 6-10 个，不要堆太多。

## 简介模板
```
[账号名] · [剧名] [年份] 精讲
正在更新：[当前进度]
关注不迷路，一部部讲完
```

## 评论区置顶
每集结尾留钩子到下一集，置顶评论承接：
- "下一期，XXX"
- "你猜后来怎么着？"
- 用一句本集最戳人的台词或问题引导讨论

## 发布节奏
- 先导合集先发，拉新
- 然后按正序逐集更新
- 每集结尾必须有"下集预告"式钩子
- 同一系列封面统一底图，feed 流里一眼认出
